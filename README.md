# نسيج وطن

خريطة المناطق الإدارية للمملكة، كل منطقة بنقشها المعروف، ولما تضغطين عليها تسمعين كلمة عن الوطن بصوت إداريات المدرسة.

فقرة إدارة المدرسة في اليوم الوطني ٩٦، المتوسطة الأولى والثانية بالخبر.

## الأصوات
تنحط في مجلد `audio` باسم المنطقة:
riyadh, makkah, madinah, qassim, hail, jouf, northern-borders, tabuk, baha, asir, jazan, najran, eastern

مثلا `audio/asir.m4a`

## الشعارات
في مجلد `img`:
- `moe.png` شعار الوزارة
- `national-day.png` شعار اليوم الوطني
