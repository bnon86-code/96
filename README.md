# وطنٌ من نسيجٍ واحد

خريطة تفاعلية للمناطق الإدارية في المملكة، كل منطقة بنسيجها المشهور وصوت إدارية من المدرسة.
فقرة اليوم الوطني ٩٦ — المتوسطة الأولى والثانية بالخبر.

## إضافة الأصوات
ارفعي كل تسجيل داخل مجلد `audio` بهذا الاسم (الامتداد m4a أو mp3 أو wav):

| المنطقة | اسم الملف |
|---|---|
| الرياض | riyadh |
| مكة المكرمة | makkah |
| المدينة المنورة | madinah |
| القصيم | qassim |
| حائل | hail |
| الجوف | jouf |
| الحدود الشمالية | northern-borders |
| تبوك | tabuk |
| الباحة | baha |
| عسير | asir |
| جازان | jazan |
| نجران | najran |
| الشرقية | eastern |

مثال: `audio/eastern.m4a`

## أسماء الإداريات
افتحي `index.html` وعدّلي قائمة `SPEAKERS` في أعلى السكربت.
